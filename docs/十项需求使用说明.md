## 1. 竞赛知识问答

**状态：已做**

支持查询通知、规程、报名条件、时间节点、提交材料、奖项设置等。数据来自赛氪 2026–2027 资料、学校 A 类竞赛名单及用户上传文档；支持简称（如「大挑」「蓝桥」「ACM」）。

**怎么用**

1. 打开首页「对话」
2. 直接提问竞赛全称或简称

**例子**

```text
大挑报名要注意什么？需要交哪些材料？
蓝桥杯 2026 报名截止时间是什么时候？
```

---

## 2. 竞赛推荐

**状态：已做**

根据专业、年级、技术方向，从竞赛台账匹配候选并给出白话推荐理由。  
（「已有项目情况」目前主要靠你在对话里自行描述，系统会结合文本理解；台账侧尚未单独建「项目库」。）

**怎么用**

1. 打开「对话」
2. 说明专业 / 年级 / 方向（可再补充做过什么项目）

**例子**

```text
推荐适合软件工程大二、偏算法方向的竞赛
我是人工智能专业，做过一个图像识别小项目，适合报什么赛？
```

---

## 3. 备赛辅助

**状态：已做**

整理比赛要求，生成备赛计划、周任务清单、材料准备建议，并可导出 Word。

**怎么用**

- **对话：** 直接说要备赛计划  
- **材料工作台 →「备赛计划」：** 填写需求后生成并下载

**例子**

```text
给软件工程大二做个蓝桥备赛计划，包含四周任务和材料清单
```

对话回复下方可点「下载备赛计划」。

---

## 4. 项目指导辅助

**状态：已做**

对申报书 / 作品说明做规则初审 + 修改建议，并给出约 5 道答辩题；可导出 Word。

**怎么用**

- **对话：** 底部「上传材料初审」（PDF / Word / 文本），或粘贴较长正文  
- **材料工作台 →「材料初审」：** 上传文件后点「开始初审」

**例子**

```text
请对这份作品说明书做初审，指出缺项，并给 5 道答辩题
```

（同时上传或粘贴正文效果最好。）

---

## 5. 预算申请辅助

**状态：已做**

按赛项、人数、地点、报名费、交通、住宿等计算明细，生成预算申请说明，导出 Word + Excel。缺参数时可估算并标明。

**怎么用**

- **对话：** 用自然语言报参数并说「做预算」  
- **材料工作台 →「预算 / 借款」：** 选「预算申请」，填表生成

**例子**

```text
蓝桥杯，3人去外省，报名费300，交通400，住2晚每晚200，市内交通100，做预算申请
```

---

## 6. 借款辅助

**状态：已做**

在预算明细基础上生成借款申请说明，可填写已批准预算文号；导出 Word + Excel。

**怎么用**

- **对话：** 说明「借款」+ 参赛费用信息（可加预算文号）  
- **材料工作台 →「预算 / 借款」：** 选「借款说明」，可填「预算文号」

**例子**

```text
同上预算，预算文号 YS-2026-031，帮我写借款单填写内容
```

或：

```text
3人外省参赛，报名费300，交通400，住2晚每晚200，借款，文号 YS-2026-031
```

## 7. 报销辅助

**状态：已做**

根据你已有材料情况整理报销说明，检查必备材料是否齐全（发票、行程单据、参赛证明、批准预算表等），可导出 Word。

**怎么用**

- **对话：** 说明报销场景与已有票据  
- **材料工作台 →「报销检查」：** 勾选已提供材料后生成

**例子**

```text
外出参赛报销，我已有发票和行程单，还缺什么？帮我整理报销说明
```

## 8. 竞赛数据统计

**状态：已做**

按年度、专业、指导教师、获奖级别等从**竞赛台账（结构化数据）**查询统计。赛项维度可结合台账竞赛名；按「单个学生」细查目前更适合在台账/导出表中查看，对话侧以汇总为主。

**怎么用**

- **对话：** 直接问统计问题  
- **数据分析页：** 选年份查看总览指标

**例子**

```text
2026 年各专业参赛和获奖情况怎么样？
统计一下指导教师指导量
```

数据需先在「竞赛台账」里有录入，否则结果会很少或为 0。

## 9. 可视化分析

**状态：已做**

自动生成参赛、获奖、教师指导等图表。

**怎么用**

- **对话：** 在统计问题中加「出图」→ 回复下方内嵌图表  
- **数据分析页：** 奖项分布饼图、专业柱状图、年度趋势、指导教师 Top10 等

**例子**

```text
2026 年各专业获奖人数，出图
```

## 10. 结果导出

**状态：已做**

支持导出常用表格 / 文档。

| 内容 | 格式 | 入口 |
|------|------|------|
| 备赛计划 | Word | 对话下载 / 工作台 |
| 材料初审报告 | Word | 对话下载 / 工作台 |
| 预算申请 | Word + Excel | 对话下载 / 工作台 |
| 借款说明 | Word + Excel | 对话下载 / 工作台 |
| 报销整理 | Word | 对话下载 / 工作台 |

## 11. 智能组队（新增）

**状态：已做**

老师创建绑定竞赛的组队活动；学生填写能力档案并报名；老师一键规则匹配 + AI 解释，确认成队后可导出，并可同步到竞赛台账。

**怎么用**

1. 打开「智能组队」或右上角「登录」
2. 演示账号：
   - 老师：`teacher1` / `teacher123`
   - 学生：`stu1`～`stu6` / `stu123`
3. **学生**：完善档案 → 报名活动  
4. **老师**：创建活动（选竞赛、队人数、角色）→ 查看报名池 →「AI 辅助组队」→ 确认成队（可勾选同步台账）→ 导出 Excel

**例子**

```text
老师登录 → 创建「蓝桥杯组队」每队 3 人，角色：算法,开发,写材料
学生 stu1~stu6 登录后报名该活动
老师点击「AI 辅助组队」→ 查看草案与 AI 建议 → 确认成队并导出
```

种子脚本（在 `backend` 目录）：`.\.venv\Scripts\python.exe scripts\seed_team_users.py`
