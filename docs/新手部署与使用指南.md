# 竞赛辅助服务智能体 · 新手部署与使用指南

把这份说明连同整个项目文件夹发给同事即可。按步骤做，大约 **15–30 分钟** 能跑起来。

---

## 一、能不能直接用？

**可以。** 本机开发环境默认用 **SQLite**，不需要单独装 MySQL。装好 Python、Node，配置一个大模型 API Key，就能用对话、知识库、台账、统计、材料工作台、智能组队等功能。

| 能力 | 说明 |
|------|------|
| 竞赛问答 / 推荐 / 备赛 | 需配置 LLM Key；知识库有样例数据 |
| 预算 / 借款 / 报销草稿 | 可用；金额由系统规则计算 |
| 台账统计 / 图表 / 导出 | 可用；可先导入样例台账 |
| 智能组队 | 可用；需登录师生账号 |

**注意：** 不要把别人的 `.env`（含 API Key）直接转发。每人用自己的 Key。

## 四、配置大模型（必做）

1. 复制环境模板：

```powershell
cd D:\学校智能体\backend
copy .env.example .env
```

2. 用记事本打开 `backend\.env`，至少改这一行：

```env
LLM_API_KEY=这里填你自己的密钥
```

常用默认（已写在模板里，一般不用改）：

```env
LLM_PROVIDER=deepseek
LLM_BASE_URL=https://api.deepseek.com
LLM_MODEL=deepseek-chat
DATABASE_URL=sqlite:///./data/competition_agent.db
```

也可换成通义千问、豆包等 OpenAI 兼容接口：改 `LLM_PROVIDER`、`LLM_BASE_URL`、`LLM_MODEL` 和对应 Key。  
启动后也可在网页 **「API 配置」** 页热切换并测连通。

申请 DeepSeek Key 示例：https://platform.deepseek.com/

## 五、安装并启动（推荐：本机双终端）

### 方式 A：一键脚本（Windows）

在项目根目录打开 PowerShell：

```powershell
cd D:\学校智能体
.\scripts\start-all.ps1
```

脚本会：创建虚拟环境（若无）、安装依赖、写入种子数据、启动后端 `8001` 与前端 `5173`。

### 方式 B：手动两步（通用）

**终端 1 · 后端**

```powershell
cd D:\学校智能体\backend
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 若还没有 .env，先按第四节复制并填 Key
$env:PYTHONPATH="."
python scripts\seed_samples.py
python scripts\seed_ledger.py
python scripts\seed_team_users.py
uvicorn app.main:app --reload --host 127.0.0.1 --port 8001
```


看到类似 `Uvicorn running on http://127.0.0.1:8001` 即成功。

**终端 2 · 前端**

```powershell
cd D:\学校智能体\frontend
npm install --registry https://registry.npmmirror.com
npm run dev -- --host 127.0.0.1 --port 5173
```

### 打开页面

| 地址 | 用途 |
|------|------|
| http://127.0.0.1:5173 | **日常使用入口（前端）** |
| http://127.0.0.1:8001/docs | 后端 API 文档（调试用） |
| http://127.0.0.1:8001/api/v1/health | 健康检查，应返回正常 JSON |

> 本机若 8000 被其他软件占用，请继续用 **8001**（前端已默认代理到 8001）。

## 六、第一次怎么点（5 分钟验收）

1. 打开 http://127.0.0.1:5173  
2. 进 **「对话」**，问一句：`大挑报名要注意什么？`  
3. 再问：`推荐适合软件工程大二、偏算法的竞赛`  
4. 打开 **「知识库 / 竞赛台账 / 数据分析 / 材料工作台」** 浏览样例  
5. 打开 **「智能组队」**，用演示账号登录：

| 角色 | 账号 | 密码 |
|------|------|------|
| 老师 | `teacher1` | `teacher123` |
| 学生 | `stu1`～`stu6` | `stu123` |

老师：看「我的活动」「指导队伍」→ 可对示例活动点 **AI 辅助组队**。  
学生：完善档案 → 报名活动。

更细的十项功能说明见：[`十项需求使用说明.md`](./十项需求使用说明.md)

## 八、常见问题

### 1. `pip` / `npm` 很慢或失败

用文中的清华 / npmmirror 镜像；公司网络需代理时自行配置。

### 2. 前端能开，对话报错 / 一直转圈

- 确认后端终端还在跑（8001）
- 打开 http://127.0.0.1:8001/api/v1/health  
- 检查 `.env` 里 `LLM_API_KEY` 是否有效、账户是否有余额  
- 浏览器 F12 → Network 看 `/api/v1/...` 是否 502（多为后端没开）

### 3. 端口被占用

```powershell
# 换端口示例
uvicorn app.main:app --reload --host 127.0.0.1 --port 8002
```

若改了后端端口，同步改 `frontend/vite.config.js` 里 `proxy./api.target`。

### 4. 智能组队没有账号

在 backend 目录执行：

```powershell
cd D:\学校智能体\backend
$env:PYTHONPATH="."
.\.venv\Scripts\python.exe scripts\seed_team_users.py
```

### 5. 想清空重来

关掉后端后删除 `backend\data\competition_agent.db`，再重新跑 seed 脚本并启动。

### 6. Docker（可选，略进阶）

需本机已装 Docker Desktop，且已准备好 `backend\.env`：

```powershell
cd D:\学校智能体
docker compose up -d --build
```

- 网页：http://127.0.0.1:8080  
- API：http://127.0.0.1:8000  

新手优先用第五节本机方式；Docker 镜像默认不带完整知识库种子时，还需挂载/导入数据。

## 九、日常开关机

**开机：** 开两个终端，分别跑后端 `uvicorn` 和前端 `npm run dev`（或再执行 `scripts\start-all.ps1`）。  
**关机：** 在对应终端按 `Ctrl+C`。

数据保存在：

```text
backend/data/competition_agent.db   # 台账、用户、组队等
backend/data/knowledge/             # 知识库文件
backend/data/exports/               # 导出文件
```

请定期备份上述目录。
