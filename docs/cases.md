# 典型应用案例与演示剧本

## 案例 A：学生赛前咨询（知识问答 + 推荐 + 备赛）

**角色**：软件工程大二学生  
**步骤**：
1. 知识库已导入《2026程序设计竞赛通知》《经费管理办法摘录》  
2. 对话：「2026程序设计竞赛报名截止时间？需要交哪些材料？」  
3. 期望：给出 2026-03-15 23:59 与材料清单，带引用  
4. 对话：「推荐适合软件工程大二、算法方向的竞赛」  
5. 期望：从台账推荐程序设计竞赛/蓝桥杯等，并说明依据字段  
6. 工作台生成备赛计划并下载 Word  

## 案例 B：教师材料指导（初审）

**角色**：指导教师  
**步骤**：
1. 准备一份简易申报书 txt/md（含项目背景、缺团队分工）  
2. 材料工作台上传，材料清单填「报名表,学生证,团队分工」  
3. 期望：规则层标出缺失项；报告含修改建议与答辩题  
4. 下载初审 Word  

## 案例 C：外出参赛经费（预算 → 借款 → 报销）

**角色**：参赛队长  
**步骤**：
1. 工作台预算：竞赛=计算机设计大赛，3人，外省，报名费600，交通400，住宿200×2晚，市内100  
2. 核对合计是否等于系统乘法结果  
3. 切换借款说明，填写预算文号，导出  
4. 报销检查：只勾选发票 → 提示缺失行程/参赛证明/预算表  

## 案例 D：学院管理决策（统计可视化）

**角色**：教务管理员  
**步骤**：
1. 打开数据分析，筛选 2025  
2. 查看奖项饼图、专业柱状图、指导教师条形图  
3. 导出参赛 Excel  
4. 对话：「2025年获奖情况怎么样？」——数字须与台账一致
