# 用户使用手册

面向：学生 / 教师 / 学院管理员。

## 登录前准备

1. 管理员在「API 配置」填入可用的 DeepSeek（或兼容）密钥并测试连通。  
2. 在「知识库」上传本学院竞赛通知、规程、经费办法。  
3. 在「竞赛台账」维护当年竞赛与参赛获奖记录。  

## 学生

### 查政策
打开「智能对话」，例如：  
「2026 程序设计竞赛报名截止时间？需要哪些材料？」  
答案应带来源引用；若无依据会明确说明知识库不足。

### 找竞赛
「我是软件工程大二，方向算法，推荐适合的竞赛」  
系统先从台账匹配，再解释理由。

### 备赛
对话提问或到「材料工作台 → 备赛计划」生成 Word 草稿。

### 经费
在「材料工作台」填写人数/交通/住宿等**真实单价**生成预算或借款说明；系统只做汇总，不编造补贴标准。

## 教师

### 材料初审
「材料工作台 → 材料初审」上传学生申报书/说明书：  
- 规则层检查材料关键词是否齐全  
- 模型层给出修改建议与答辩预演题  
- 可下载 Word 报告  

### 指导统计
「数据分析」查看指导教师指导量；或对话问「2025 年获奖情况」。

## 管理员

### 台账
「竞赛台账」维护竞赛与参赛记录。  

### 分析与导出
「数据分析」查看图表，导出 Excel。  

### 知识治理
「知识库」启停/删除文档；新学年上传新通知即可，无需改代码。  

## 注意事项

1. 统计结果以台账为准。  
2. 政策问答以知识库原文为准。  
3. 财务草稿需人工审核后才能正式提交。
