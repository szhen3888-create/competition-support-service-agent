## 哪些可以删、哪些要留

| 路径 | 说明 |
|------|------|
| `backend/.venv/`、`frontend/node_modules/` | 依赖环境，可删后重装，不必打包发给别人 |
| `backend/data/exports/`、`uploads/` | 运行时临时文件，可随时清空 |
| `knowledge/**/raw/`、`list_all.json` | 抓取缓存，已忽略；需要时再跑 `scripts/kb/fetch_*.py` |
| `knowledge/*/contests/*.md` | **正式知识源，请保留** |
| `backend/data/knowledge/` | **已入库索引，请保留**（或删后用 kb 脚本重新 ingest） |
| `backend/.env` | 含 API Key，**不要外传** |

## 常用维护命令

```powershell
# 重新抓取赛氪（可选）
.\backend\.venv\Scripts\python.exe scripts\kb\fetch_saikr_contests.py
.\backend\.venv\Scripts\python.exe scripts\kb\ingest_saikr_kb.py

# 从 A 类 Excel 重建学校知识库
.\backend\.venv\Scripts\python.exe scripts\kb\build_a_class_kb.py

# 种子账号 / 台账
cd backend
$env:PYTHONPATH="."
.\.venv\Scripts\python.exe scripts\seed_samples.py
.\.venv\Scripts\python.exe scripts\seed_ledger.py
.\.venv\Scripts\python.exe scripts\seed_team_users.py
```
